# @zerowire/runtime

Zero-dependency TypeScript runtime for zerowire zero-copy flyweight views, static buffer ring pools, and branded primitives.

## Overview

`@zerowire/runtime` provides the runtime primitives and base views generated by the zerowire Ahead-of-Time compiler. It enables reading structured binary buffers and wire JSON directly via `DataView` without allocating intermediate JavaScript heap objects.

## Installation

```bash
pnpm add @zerowire/runtime
# or
npm install @zerowire/runtime
# or
bun add @zerowire/runtime
```

## Features

- Zero runtime dependencies: Lightweight package containing zero external dependencies.
- Zero-copy flyweight views: Access primitives and strings directly from underlying `ArrayBuffer` slices.
- Static buffer and tape pools: Pre-allocated `ArrayBuffer` and `Uint32Array` ring pools to eliminate garbage collection pressure on high-frequency paths.
- Physical type brands: Nominal branded types (`u8`, `u16`, `u32`, `u64`, `i8`, `i16`, `i32`, `i64`, `f32`, `f64`) to declare physical integer and float widths in TypeScript.

## Usage

### Physical Branded Types

```typescript
import { compileWireCodec, type u32, type f64 } from "@zerowire/runtime";

export interface MarketTick {
  price: f64;
  volume: u32;
  symbol: string;
}

export const MarketTickCodec = compileWireCodec<MarketTick>();
```

### Flyweight Decoding

```typescript
// Incoming raw Uint8Array from network or worker
const tick = MarketTickCodec.validateAndView(rawBytes);

if (tick) {
  // Numeric values are read directly from DataView offsets
  console.log(tick.price, tick.volume);

  // Strings are lazily decoded on demand using fast unrolled ASCII loops
  console.log(tick.symbol);
}
```

### Buffer and Tape Ring Pools

For maximum throughput in message loops:

```typescript
import { StaticBufferPool, StaticTapePool } from "@zerowire/runtime";

// Acquire a pre-allocated 64KB buffer slice without GC allocations
const buf = StaticBufferPool.acquire(65536);

// Acquire a static structural index tape for JSON parsing
const tape = StaticTapePool.acquire(4096);
```
