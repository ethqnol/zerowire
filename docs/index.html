AOT TypeScript Binary Codec

Ahead-of-Time TypeScript to Wire Codec

zerowire compiles static TypeScript interfaces into branchless DataView validators, Minimal Perfect Hash tables, and lazy flyweight proxy views. Eliminates JSON.parse overhead and heap allocation on high-throughput paths.

pnpm add @zerowire/runtime && pnpm add -D @zerowire/unplugin

Overview

Traditional validation libraries such as Zod, Valibot, or ArkType parse wire JSON into dynamic JavaScript objects before inspecting fields. In high-frequency Node.js, Bun, or Cloudflare Worker servers, this causes two critical bottlenecks:

1. Eager heap allocation: Allocating V8 hidden classes, arrays, and strings for every single field in a payload, even if only a small subset of fields are inspected.
2. Garbage collection spikes: Thousands of transient heap objects per second triggering V8 Scavenge pauses and tail latency spikes.
3. Branch misprediction: Deeply nested conditional validation trees flushing CPU pipelines under polymorphic loads.

zerowire solves this by extracting TypeScript types at build time using the native Rust oxc_parser and compiling them into flat, branchless byte checkers and lazy DataView proxy views. Unread fields never allocate a single byte on the V8 heap.

Zero Eager Allocation
Validation operates directly over raw Uint8Array slices without allocating JavaScript objects.
No tsc Dependency
All type extraction and AST analysis run in native Rust via Oxc crates without ts-patch or compiler API lag.
Branchless Validation
Accumulates field integrity bitwise across struct headers, branching once at the end of the header block.
Automatic Struct Packing
Sorts fields by descending alignment (8B -> 4B -> 2B -> 1B) to guarantee zero interior padding holes.

Quick Start

Using zerowire requires two steps: defining your schema with physical types, and calling compileWireCodec<T>().

Step 1. Define Your Schema

Use standard TypeScript interface syntax. Import physical branded types (such as u32 or f64) from @zerowire/runtime to specify memory widths:

src/schema.ts 
import { compileWireCodec, type u32, type f64 } from "@zerowire/runtime";

export interface TradeExecution {
  timestamp: f64;         // 8-byte IEEE-754 float
  tradeId: u32;           // 4-byte unsigned integer
  side: "BUY" | "SELL";   // 1-byte enum (0 or 1)
  isMaker: boolean;       // 1-byte boolean (0 or 1)
  symbol: string;         // Dynamic UTF-8 slice (8-byte header descriptor)
  fills: f64[];           // Dynamic array (8-byte header descriptor)
}

// Replaced at build time by @zerowire/unplugin with the compiled codec class
export const TradeExecutionCodec = compileWireCodec<TradeExecution>();

Step 2. Validate and Access Wire Data

When binary or JSON payloads arrive over a socket or HTTP request, call validateAndView(rawBytes):

src/consumer.ts 
import { TradeExecutionCodec } from "./schema";

function handleIncomingPayload(rawBytes: Uint8Array) {
  // Validates buffer bounds and struct fields in ~5 nanoseconds
  const trade = TradeExecutionCodec.validateAndView(rawBytes);

  if (!trade) {
    throw new Error("Corrupted or invalid payload");
  }

  // Primitives read directly from fixed DataView byte offsets
  console.log(trade.timestamp, trade.tradeId, trade.side);

  // String and array getters decode lazily on first access and memoize
  console.log(trade.symbol);
}

HTTP Request Validation

In web frameworks (Hono, Fastify, Express, or standard web fetch), avoid parsing incoming bodies as JSON strings. Instead, consume the raw ArrayBuffer:

src/server.ts 
import { Hono } from "hono";
import { TradeExecutionCodec } from "./schema";

const app = new Hono();

app.post("/orders", async (c) => {
  // 1. Read raw byte stream directly into a Uint8Array
  const rawBuffer = new Uint8Array(await c.req.arrayBuffer());

  // 2. Validate without JSON.parse() overhead
  const order = TradeExecutionCodec.validateAndView(rawBuffer);
  if (!order) {
    return c.text("Invalid payload structure", 400);
  }

  // 3. Route or filter based on numeric fields with zero string decoding
  if (order.tradeId > 100000 && order.side === "BUY") {
    console.log("Priority order received for", order.symbol);
  }

  return c.text("OK", 200);
});

Worker Thread Messaging

Transferring structured objects between Node.js worker_threads or browser Web Workers usually invokes structuredClone(), duplicating the object graph.

zerowire allows you to serialize an object into a flat ArrayBuffer or SharedArrayBuffer in a single pass. Both threads read and write memory directly without serialization overhead:

src/worker-dispatch.ts 
import { Worker } from "node:worker_threads";
import { TradeExecutionCodec } from "./schema";

// 1. Single-pass binary serialization directly to a packed Uint8Array
const binaryPayload = TradeExecutionCodec.encodeBinary({
  timestamp: Date.now(),
  tradeId: 42000,
  side: "BUY",
  isMaker: true,
  symbol: "ETH-USDT",
  fills: [3500.5, 3501.0],
});

// 2. Transfer buffer without structuredClone copying
worker.postMessage(binaryPayload.buffer, [binaryPayload.buffer]);

Flyweight Proxy Views

The generated flyweight proxy class provides typed property access directly over an underlying DataView. It implements two micro-optimizations:

1. Unrolled ASCII decoding: Short strings (4 bytes or fewer, such as currency codes, statuses, and tickers) decode via unrolled String.fromCharCode instructions, completely avoiding V8 C++ TextDecoder binding overhead.
2. Lazy memoization: When a string or dynamic array getter is first evaluated, it defines a non-configurable property on the proxy instance. Subsequent reads become instant O(1) property lookups.

Generated Flyweight Getter Pattern 
// Short string (<= 4 bytes) fast path emitted by zerowire
get symbol() {
  const off = this._view.getUint32(12, true);
  const len = this._view.getUint32(16, true);
  if (len === 3) {
    const val = String.fromCharCode(
      this._bytes[off],
      this._bytes[off + 1],
      this._bytes[off + 2]
    );
    Object.defineProperty(this, "symbol", { value: val });
    return val;
  }
  // Fallback to shared TextDecoder for longer strings
  const val = sharedDecoder.decode(this._bytes.subarray(off, off + len));
  Object.defineProperty(this, "symbol", { value: val });
  return val;
}
