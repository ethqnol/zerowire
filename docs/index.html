Ahead-of-Time TypeScript Binary Codec

Zero-allocation validation.
Zero JSON.parse overhead.

zerowire compiles static TypeScript interfaces into branchless DataView validators, Minimal Perfect Hash jump tables, and lazy flyweight proxy views. Powered by Rust, Oxc AST parsing, and WebAssembly SIMD.

pnpm add @zerowire/runtime && pnpm add -D @zerowire/unplugin

Overview

Every major validation library in JavaScript operates after incoming wire data has already been deserialized via JSON.parse(). zerowire operates directly on raw Uint8Array or ArrayBuffer payloads.

Zero Eager Heap Allocation
Validation executes directly over byte slices. String and array materialization is deferred until fields are actually read.
No tsc Dependency
AST parsing and type lowering execute at native speed in Rust using Oxc crates, without monkey-patching tsconfig.
Branchless CPU Speculation
Fixed headers accumulate error bits via bitwise OR and XOR operations, eliminating branch mispredictions on hot paths.

Quick Start

Write pure TypeScript interfaces and invoke the compileWireCodec macro. The compiler transforms call sites into high-performance byte decoders.

schema.ts
import { compileWireCodec, type u32, type f64 } from "@zerowire/runtime";

export interface TradeExecution {
  timestamp: f64;
  tradeId: u32;
  side: "BUY" | "SELL";
  isMaker: boolean;
  symbol: string;
  fills: f64[];
}

// Replaced at compile time with the AOT codec class
export const TradeExecutionCodec = compileWireCodec<TradeExecution>();

Flyweight Views

When validating incoming wire buffers, flyweight views decode primitives on fixed offsets and lazily memoize string or array fields on read.

server.ts
// Zero-copy validation over incoming raw network bytes
const view = TradeExecutionCodec.validateAndView(rawBytes);

if (view) {
  // Primitives read directly from DataView registers
  console.log(view.timestamp, view.tradeId, view.side);

  // Strings decode on demand using unrolled ASCII char codes
  console.log(view.symbol);
}

Binary Serialization

Encode standard JavaScript objects directly into flat, memory-aligned binary structs in a single pass without intermediate allocations.

encode.ts
const binary = TradeExecutionCodec.encodeBinary({
  timestamp: Date.now(),
  tradeId: 10420,
  side: "BUY",
  isMaker: true,
  symbol: "BTC-USDT",
  fills: [65000.5, 65002.0],
});

// Branchless binary validation runs in 5.92 nanoseconds
const valid = TradeExecutionCodec.validateBinary(
  new DataView(binary.buffer, binary.byteOffset, binary.byteLength)
);

Minimal Perfect Hash Functions

For tagged unions and string literal enums, the Rust compiler synthesizes a Minimal Perfect Hash Function at build time:

Formula
h(w, L) = ((w ^ L) * MAGIC_MULTIPLIER) >>> (32 - log2(M))

This maps arbitrary string keys to dense array indices in three CPU instructions without string decoding or hash map lookups.

WASM SIMD Tokenizer

For payloads exceeding 4 KB, the WebAssembly v128 SIMD scanner scans 16 bytes per instruction, using carry-less prefix-XOR tricks to mask quote characters and populate structural tapes at over 2.5 GB/s.

Bundler Setup

zerowire integrates into all modern build systems via @zerowire/unplugin.

vite.config.ts
import { defineConfig } from "vite";
import { zerowireVite } from "@zerowire/unplugin";

export default defineConfig({
  plugins: [zerowireVite()],
});
